# Ledger autoresearch research update

Published results from the Gemma 31B and 12B searches, plus the completed Haiku-constructor / Gemma-31B-reader search. Open `index.html`; all charts and page data are embedded, so it also works offline.

Each progress tab combines all completed train scores with the available Calendar evaluations for the corresponding configurations. The 12B Calendar sweep covers all 37 promoted candidates. The page also summarizes the five completed Astra consultations and their tested follow-ups.

`snapshot.json` contains aggregate metrics, candidate descriptions, and source hashes; `analysis.md` explains the interpretation and limits. Private trajectory text, ledgers, and per-case predictions are not included.
