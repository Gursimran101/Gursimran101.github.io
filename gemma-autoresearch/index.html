2 / Experiment

Search over the ledger construction step

Complete trajectory + precomputed evidence → Gemma factual ledger → fixed sanitizer → frozen Gemma reader → LDS-v2

What changes

  • Opus proposes constructor prompts, evidence tools, and sometimes a two-pass Gemma constructor. Gemma runs both passes.
  • Opus inspects train errors; Astra can advise. For 12B, Opus can build and run new evidence tools.
  • Gemma receives the chosen prompt and evidence; it does not need to perform tool calls itself.

LDS-v2 = ½ balanced verdict accuracy + ½ construct macro-F1. Constructs: wrong parameter, wrong entity, extra operation, prohibited action.

3 / Results

Train improves; Calendar transfer depends on the configuration.

The highest Calendar score was found by comparing every promoted candidate on Calendar. It is an observed maximum, not the result of selecting the train winner in advance.

How did the 37 promoted 12B candidates transfer?

31B gains +0.0692 over the train ledger baseline, but only +0.0047 on Calendar. The winner is 0.0361 below the Calendar direct-trajectory control.

Where do the gains come from? Component metrics and tasks

For 31B train, the gain decomposes into about +0.0139 from balanced accuracy and +0.0553 from construct F1. On Calendar, −0.0208 from accuracy is offset by +0.0255 from construct F1. These are arithmetic contributions to LDS, not causal mediation estimates.

5 / What the results mean

The tool-assisted pipeline helps on train; factual relationships look important.

  • Overall result: the searched tool-assisted ledger configurations improve train LDS over both the no-tools ledger and direct-trajectory baselines. We treat this as a gain from the overall prompt + evidence pipeline.
  • Plausible mechanism: source-indexed evidence and structured prompts help preserve who an action targeted, where a value came from, and which restriction applies. Source-paired comparisons and complete action coverage feature in the strongest 31B lineage; scope/action juxtaposition features in the best 12B prompt.
  • Unexpected finding: more evidence or another verification pass did not automatically help. One matched 12B second-pass design reduced LDS from 0.5767 to 0.5211.

Working interpretation: better organization of relevant evidence helps the frozen reader. Many 12B configurations also exceed the Calendar ledger baseline, but train ranking did not identify the strongest Calendar configuration. Ledger fidelity and performance on a fresh task remain open.

The overall configuration changed prompts and evidence together. We do not need to separate their individual effects to report the pipeline gain. A train gain alone does not establish that the same mechanism generalizes.

Supporting matched 12B comparisons

Verified against saved prompts, evidence stages, checkpoint, data hashes, reader settings and evaluator source. All scores use the same 144 train cases.

Important confound: “same prompt + new tool” was not always a clean ablation

Appending T34 was described as an evidence-only test. The saved prompt text does match, but the evaluator source hash changed. Its 0.5024 → 0.5101 comparison (+0.0077) therefore cannot isolate the tool effect. Other tool-removal variants also changed prompt wording or evidence limits.

We should rerun tool ablations with the exact prompt, source version, caps and serving setup fixed.

Paired verdict changes and exploratory uncertainty

These intervals are conditional on already selected configurations. They do not correct adaptive selection, quantify inference repeatability or establish a causal effect outside these cases. No significance claim is made.

6 / Failures and unexpected findings

Screen rankings and extra processing were unreliable.

Observed failures

  • 31B two-pass drafts with incompatible headings lost content in sanitization. Other candidates exhausted the constructor output limit.
  • The 31B winner increased benign false flags on train: 20.8% → 31.9%.
  • 31B second passes only saw the draft. The tested 12B second pass saw the original trajectory but still reduced LDS.
